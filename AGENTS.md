# Communication preferences

- Write every mathematical expression in ASCII on a single line so it renders correctly in command-line interfaces.
- Do not use LaTeX commands, Unicode mathematical symbols, or multiline display equations in user-facing responses.

# Project handoff

- Before any work on this repository, read `docs/00_handoff.html`: it records the state of the two papers (T-IV hierarchical Bayesian, CoPL), the collaboration rules agreed with the author, the frozen run identifiers behind every number, and the open items. The per-project notes it points to (`docs/fully_bayesian/my_papers/claude_notes/`, `docs/copl/claude_notes/`) are the memory of previous sessions; keep adding numbered notes there instead of rewriting old ones.
