\begin{abstract}
최근에는 다수 사용자 피드백 데이터로부터 개별 사용자의 선호도를 LLM, control system에 반영하려고 한다.
그런데 다수의 사용자들의 good, bad feedback 만으로 그 사용자의 선호도, 특히 보상함수를 추정하는 것은 어렵다.
이를 위해 최근에는 피드백 데이터를 기반으로 딥러닝 학습을 하여 사용자 선호도를 보다 정확하게 추정하고자 한다.
그러나 이러한 point estimation 방식은 사용자 보상함수의 불확실성을 고려하기 어렵다.
한편, Bayesian inference는 이러한 장점이 있다.
우리는 hierarachical fully Bayesian inference를 이용해 posterior의 불확실성, 그리고 해당 사용자의 불확실성을 동시에 추정하려고 한다.
[이런 환경]에 적용해보았으며, [이런 결과]가 나왔다.
\end{abstract}

For user $u$, we define the latent personalized reward function as
\begin{equation*}
    r_{ui} = r_u(\tau_{ui})
    = \bm\theta_u^\top \bm z_{ui}
    = \bm\theta_u^\top \phi(\tau_{ui}).
\end{equation*}

The binary multi-user feedback $y_{ui} \in \{0, 1\}$ is labeled based on this personal reward. To express this observation process using an explicit equality form while maintaining the logistic choice structure, we introduce a latent variable formulation:
\todo[inline]{아예 personal reward 말고, 자신만의 $\theta_u$가 있다고 쓰는게 나으려나}
\todo[inline]{To expres.. 부분 제거, 우리가 제안하는게 아님. 아예 indicator 뺄까 싶기도 하고}
\begin{equation*}
    y_{ui} = \mathbb{I}(r_{ui} + \eta_{ui} > 0), \qquad
    \eta_{ui}\sim \mathrm{Logistic}(0,1).
\end{equation*}

where $\mathbb{I}(\cdot)$ is the indicator function, and $\eta_{ui}$ represents the random observation noise following a standard logistic distribution. By integrating out the latent logistic noise $\eta_{ui}$, this formulation can be equivalently expressed as an explicit choice probability form:
\begin{equation*}
P(y_{ui} = 1 \mid \bm{\theta} _u, \bm{z}_{ui}) = \sigmoid \! \left( \bm{\theta}_u^{\top } \bm{z}_{ui} \right) .
\end{equation*}

우리 목표는 parameter $\theta_u$의 posterior를 inference 하는 것.

각 사용자들은 본인의 선호를 갖고 있지만, 그걸 다수로 모아두고 보면 어떤 경향성을 가진다. 우리는 다수 사용자가 어떤 공통적인 분포를 띈다고 가정한다,
\begin{equation*}
    \bm\theta_u \mid \mu, \Sigma \sim \N(\mu, \Sigma)
\end{equation*}
여기서 $\mu$는 poulation-average preference vector, $\Sigma$는 variation, correlation in preference dimensions across users 이다.

    \end{aligned}
\end{equation*}
