0. 공통 표기와 판정 규칙

u = 1..U  population 평가자,  * = held-out 평가자,  i = 에피소드
z_ui in R^d (bias 포함),  y_ui in {0,1}
y_ui ~ Bernoulli( sigma(theta_u^T z_ui) ),   theta_u = gamma (.) theta~_u,   theta~_u ~ N(mu, Sigma)
(mu, Sigma) ~ NIW(m0 = 0, kappa0 = 1, nu0 = d + 2, Lambda0 = lambda0 * I)
gamma_g ~ Bernoulli(pi),  pi ~ Beta(1, 1)

LOEO: 평가자 *를 빼고 적합 -> 문맥 D_{*,t} (시간순 앞 절반의 첫 t개) -> holdout H_* (뒤 절반)
p^(m)_{*j,t} = sigma(z_{*j}^T theta^(m)_{*,t}),   p^_{*j,t} = (1/M) sum_m p^(m)_{*j,t}

주 지표 (01 문서):  MLPD_*(t) = (1/|H_*|) sum_{j in H_*} log p(y_{*j} | p^_{*j,t})
macro: mean_* MLPD_*(t),  SE = sd_* / sqrt(n_folds)
paired 차이: dELPD_*(t) = sum_j [ lpd_{*j}(t) - lpd_{*j}(0) ],  SE = sqrt(n * var_j)
불확실성 분해:  p^(1-p^) = E_m[p^(m)(1-p^(m))] + Var_m(p^(m))  =  U_ale + U_epi

판정 규칙은 데이터를 보기 전에 다음으로 고정한다.

  • 우열: macro MLPD 차이가 평가자 단위 SE보다 크면 "다르다", 아니면 "같다". ELPD 차이는 4 미만이면 작다고 보고, 4 이상이면 SE와 비교한다(Vehtari).
  • 선택: 전체 뱅크 대비 paired 차이가 1 SE 이내인 가장 작은 크기(one-SE 규칙).
  • 분해의 분리: Spearman(U_epi, U_ale)의 절대값이 0.5 미만이면 분리된 것으로 본다(Mucsányi 벤치마크의 0.78~0.88과 대비).
  • 불확실성의 유용성: U_epi로 오답(1[p^ > 1/2] != y)을 예측하는 AUROC가 0.5에서 SE 이상 떨어져 있으면 유용하다고 본다.

E1. 기본 LOEO 실행 부분 지지

실행 outputs/loeo/20261001_170056 · lambda0 = 1 · 시드 42 · 예산 0/5/10/20/최종 · 선택 예산 (0, 10) · 70분

H1.1 cold start 전이

가설

H1.1:  MLPD_prop(0) >= MLPD_pooled  (population posterior predictive가 pooled 로지스틱만큼은 전이된다)

근거

pooled는 모든 평가자를 한 명으로 보고 theta를 하나 추정한다. 계층 모형의 cold start 예측은 p(theta_* | D_pop) = integral N(theta_*; mu, Sigma) p(mu, Sigma | D_pop) 로, pooled의 점 추정을 "평균 mu 주변의 분포"로 넓힌 것이다. 이질성이 실제로 있으면 넓힌 쪽이 log score에서 손해를 덜 본다.

결과

MLPD(0):  proposed -0.698 +- 0.049   hb_full -0.694 +- 0.041   ebmap -0.720 +- 0.062   pooled -0.717 +- 0.057
AUROC(0): proposed  0.734 +- 0.045   hb_full  0.688 +- 0.038   pooled  0.692 +- 0.043

해석과 판정

MLPD는 pooled와 SE 안에서 같다("더 낫다"는 아니다). AUROC는 proposed가 0.04 높고, 이 차이는 포함 사전분포에서 온다(hb_full은 pooled와 같다). 지지 (동등성). 다만 평가자 하나(김진명)는 pooled가 0.10 더 좋다. 이질성이 작은 평가자에게는 넓힌 예측이 손해라는 뜻이고, 이는 H1.3으로 이어진다.

H1.2 순차 개인화

가설

H1.2a:  MLPD_prop(t)가 t에 대해 증가하고,  MLPD_prop(20) - MLPD_pooled(20) > SE
H1.2b:  MLPD_indep(t) < MLPD_prop(t)  for all t <= 20   (사전분포 없는 개인화는 소수 라벨에서 실패)

근거

라벨 t개의 로지스틱 우도는 d = 41차원에서 t < d일 때 식별 불능이다. 사전분포 N(mu, Sigma)가 그 부족분을 채우므로 proposed는 t가 작아도 정의되고, indep는 정규화 L2에 의존해 사실상 pooled보다 못해야 한다.

결과

t:          0       5       10      20      final
proposed  -0.698  -0.624  -0.620  -0.547  -0.564
pooled    -0.717  -0.714  -0.675  -0.692  -0.691
indep       --    -0.824  -0.911  -0.839  -0.673
dMLPD(20) = proposed - pooled = +0.145  (SE 0.02~0.03)

해석과 판정

단조 증가하고(final은 평가자 구성이 달라 비교 불가), t = 20에서 pooled보다 0.145 좋다. indep는 모든 예산에서 pooled보다도 나쁘다. 지지.

H1.3 이득의 분포

가설

H1.3:  dMLPD_*(5) = MLPD_*(5) - MLPD_*(0) >= 0  for every held-out evaluator *

근거

Bayesian 갱신은 기대 log score를 낮추지 않는다(사전분포가 맞다면). 라벨 5개면 posterior가 자기 쪽으로 움직여야 한다.

결과

dMLPD(5):  강신길 +0.018  김재호 -0.062  김진명 -0.031  김태근 -0.001  박재일 +0.119
           신민철 +0.008  이강근 +0.504  이지환 +0.077  조현석 +0.056  한규택 +0.052

해석과 판정

라벨 30개 안팎의 세 명(김재호, 김진명, 김태근)은 0 또는 음수다. holdout 15~18개에서 MLPD의 SE는 대략 sd(lpd)/sqrt(15) = 0.15 수준이라 음수가 통계적으로 유의하지는 않지만, 세 lambda0에서 같은 방향(E2)이라 잡음만은 아니다. 기각 (보편성). 이득은 긴 스트림 다섯 명에 집중된다. 원인 후보는 E5에서 분리한다.

H2.1 분해의 거동

H2.1a:  mean_j U_epi,j(t)가 t에 대해 감소        (epistemic은 피드백으로 줄어든다)
H2.1b:  mean_j U_ale,j(t)가 t에 대해 거의 일정     (aleatoric은 피드백과 무관)
H2.1c:  |Spearman_j(U_epi, U_ale)| < 0.5          (두 성분이 같은 것을 재지 않는다)

결과

U_epi:   0.070  0.057  0.045  0.034  0.029    (t = 0, 5, 10, 20, final)
U_ale:   0.145  0.154  0.161  0.160  0.162
rho:    -0.37  -0.12  -0.02  +0.33  +0.20

세 조건 모두 성립. 지지. U_ale이 약간 오르는 것은 개인화로 p^가 0.5에서 멀어지며 p(1-p)가 아니라 E_m[p^(m)(1-p^(m))]이 재배치되는 효과로 보이며 크기는 작다.

H2.2 epistemic의 유용성

H2.2:  AUROC( wrong_j = 1[p^_j > 1/2] != y_j ;  score = U_epi,j ) > 0.5 + SE   for all t

근거

U_epi가 크면 particle들이 그 에피소드의 판단에 합의하지 못한 것이므로 틀릴 확률이 높아야 한다. 이것이 "posterior가 얼마나 믿을지 알려준다"의 조작적 정의다.

결과

correctness AUROC(U_epi):  0.49  0.55  0.57  0.63  0.57   (t = 0, 5, 10, 20, final)
correctness AUROC(|p^-1/2|): 0.58  0.63  0.65  0.67  0.66   (총 불확실성 기준, 참고)

해석과 판정

cold start에서는 우연 수준이고 t = 20에서야 0.63이다. 총 불확실성 |p^ - 1/2|가 모든 t에서 더 낫다. 즉 cold start의 U_epi는 "어느 에피소드가 어려운가"가 아니라 "population이 얼마나 갈라지는가"를 재고 있고, 그 갈라짐은 해당 평가자의 오답과 무관하다. 부분 지지 (t >= 10에서만). 논문 주장 수위를 "개인화가 진행되면 epistemic이 오답을 가려낸다"로 낮춘다.

H2.3 신뢰 판정 규칙

reliable(t) :=  AUROC_lo(t) > 1/2  and  AUROC_hi(t) - AUROC_lo(t) < w_max,   w_max = 0.15
H2.3:  reliable 비율이 t에 대해 증가해 t = 20에서 과반

결과

AUROC_lo:  0.24  0.28  0.38  0.56  0.39      reliable 비율: 0  0  0  0  0.10

구간 하한은 t와 함께 오르지만(t = 20에서 0.5를 넘음) 폭이 0.27~0.65라 w_max = 0.15는 한 번도 만족되지 않는다. 구간은 particle 하나씩의 AUROC를 bootstrap하므로 population 이질성이 그대로 폭이 된다. 기각 (규칙 설계). E7에서 재설계.

E2. 사전분포 척도 lambda0 민감도 주 가설 기각

실행 outputs/loeo_lam01 (lambda0 = 0.1), outputs/loeo_lam001 (0.01) · main만 · 각 36분

가설

inverse-Wishart 사전 평균:  E[Sigma] = Lambda0 / (nu0 - d - 1) = lambda0 * I        (nu0 = d + 2)
사후 평균 근사:             E[Sigma | .] ≈ (Lambda0 + S) / (nu0 + U - d - 1) = (lambda0 * I + S) / (U + 1)
                           S = sum_u (theta~_u - theta_bar)(theta~_u - theta_bar)^T
대각 성분:                 Sigma_jj ≈ (lambda0 + U * tau_j^2) / (U + 1),   tau_j^2 = 실제 평가자 간 분산
U = 9, lambda0 = 1, tau_j = 0.2 이면  Sigma_jj ≈ (1 + 0.36) / 10 = 0.136,  sd 0.37  (실제 0.2의 거의 2배)

H2a (예측):  lambda0를 0.1, 0.01로 줄이면 cold start 예측이 덜 평평해져 MLPD(0)와 ECE(0)가 개선된다
H2b (개인화): 라벨 5개에서 posterior가 과하게 움직이는 현상이 줄어 소수 라벨 평가자의 dMLPD(5)가 0 이상이 된다
H2c (선택):  피처가 많을수록 예측 분산만 커지던 효과가 줄어 Q(S_k) 곡선이 k에 대해 오른다

근거

위 근사식에서 U가 작으면 Sigma 사후분포는 lambda0에 지배된다. 과대 추정된 Sigma는 (1) cold start particle을 넓게 퍼뜨려 평균 예측을 1/2로 수축시키고, (2) 사전 정밀도 Sigma^-1가 작아 라벨 몇 개가 posterior를 크게 움직이게 하며, (3) 피처마다 분산을 더해 d가 클수록 예측이 평평해진다. 셋 다 E1에서 관측된 현상이므로 한 원인으로 묶어 세웠다.

해석과 판정

  • H2a 기각. MLPD와 ECE는 모두 SE 안에서 같다. U_epi는 근사식대로 줄었으니 Sigma가 사전분포에 끌리는 것은 사실이지만, 그것이 예측 품질의 병목은 아니다. cold start의 평평함은 Sigma 척도가 아니라 다른 데서 온다(E6).
  • H2b 기각. 소수 라벨 평가자의 dMLPD(5)는 세 설정에서 같은 부호, 같은 크기다. 사전 정밀도를 100배 키워도 안 바뀌므로 "posterior가 과하게 움직인다"가 원인이 아니다(E5).
  • H2c 미검정. select 스테이지를 lambda0 변경으로 돌리지 않았다. 다만 main에서 hb_full과 proposed가 같다는 사실로 보아 결과가 바뀔 가능성은 낮다.
  • 부수 발견 두 가지. (i) epistemic의 오답 예측력이 lambda0가 작을수록 좋아진다(0.49 → 0.62). 좁은 사전분포에서 U_epi는 population 갈라짐이 아니라 데이터 희소성을 더 반영하게 되기 때문이다. (ii) 공통/개인 분류가 lambda0에 크게 의존한다. q_j의 분모 sqrt(Sigma_jj)가 사전분포에 좌우되므로 당연한 결과이고, 예측 성능으로는 lambda0를 고를 수 없으므로 분류는 사전분포 두 값에서 함께 보고하고 양쪽에서 같은 사실만 결론으로 쓴다.

H2a, H2b 기각 · lambda0 = 1을 기본으로 유지하고 0.01을 민감도로 보고. 예측 둔감성은 강건성 근거.

E3. 선택 점수 예산에 t = 20 추가 기각

실행 outputs/loeo_selb20 · B = {0, 10, 20} · all · 70분

가설

H3:  B = {0, 10, 20}으로 Q를 정의하면 k* > 1 이고 dQ_loso(Bounce) < 0
     (개인 피처 — Bounce impulse 등, PIP 0.8~0.9 — 는 cold start가 아니라 개인화 뒤에 기여한다)

근거

E1에서 Bounce impulse는 "specific"(개인차가 큰 피처)로 분류됐다. 개인차가 큰 피처는 population 평균 mu_j가 작아 t = 0 예측에는 기여하지 못하고, 개인 posterior가 자리 잡은 뒤에야 기여해야 한다. B에 20을 넣으면 그 기여가 Q에 잡혀야 한다.

결과

k* = 1 (IMU_VerAccelVal__p2p, 10/10),  dQ(k=1 vs full) = +0.020+-0.011,  dQ(k=10) = +0.003+-0.011
dQ_loso(Bounce) = +0.004+-0.006,  dQ_loso(VerAccel) = -0.034+-0.023,  Pitch -0.004,  LongAccel -0.003,  LatAccel +0.005

해석과 판정

E1과 수치까지 거의 같다. t = 20은 긴 스트림 다섯 명에서만 계산되므로 B의 평균에서 가중치가 1/3이지만, 그 다섯 명에서도 bounce 피처가 기여했다면 dQ_loso(Bounce)가 음수로 돌아섰을 것이다. 그렇지 않았다. 기각. 개인 피처의 높은 PIP는 "모형이 그 피처에 개인차를 부여한다"는 뜻이지 "그 개인차가 held-out 예측을 개선한다"는 뜻이 아니다. 선택 결론(수직 가속도 하나)은 B에 둔감하므로 B = {0, 10, 20}을 확정 설정으로 쓴다.

E6. cold start 과소 확신의 원인 예정

배경

E1에서 cold start의 ECE가 0.27이고 calibration slope가 1을 크게 넘는다(예측이 1/2 근처로 몰림). E2에서 Sigma 척도는 원인이 아니었다.

posterior mean 예측:  p^_j = (1/M) sum_m sigma(z_j^T theta^(m))
plug-in 예측:         p~_j = sigma( z_j^T theta_bar ),   theta_bar = (1/M) sum_m theta^(m)
Jensen:  theta^(m)가 퍼져 있으면  |p^_j - 1/2| <= |p~_j - 1/2|   (sigmoid 평균은 항상 1/2 쪽으로 수축)

H6a (수축):  slope(p~) ≈ 1 이고 slope(p^) > 1 이면 과소 확신은 particle 이질성에 의한 Jensen 수축이다
H6b (신호):  slope(p~)도 1보다 크면 population 평균 theta_bar 자체가 holdout에서 약한 것이고, 수축이 아니라 신호 부족이다

근거

01 문서 5.6의 임상 예측 연구는 posterior mean 예측이 plug-in보다 slope가 1에 가깝다고 보고했다. 우리 데이터에서 반대라면 cold start particle의 이질성이 비정상적으로 크다는 뜻이다.

설계

코드에 mlpd_plugin, ece_plugin, cal_slope_plugin이 추가되어 E4 이후 모든 실행의 리포트 csv에서 바로 읽을 수 있다(p~는 logit 평균의 sigmoid로 계산하며 이는 sigma(z^T theta_bar)와 정확히 같다). 추가 실행은 필요 없다.

판정

H6a이면 cold start에서는 p~로 결정하고 p^로 불확실성을 보고하는 "분리 보고"를 Discussion에 제안한다. H6b이면 과소 확신은 데이터 한계이며 그대로 보고한다. 어느 쪽이든 posterior mean을 주 예측으로 유지한다(log score 기준에서는 p^가 p~보다 나쁠 수 없다는 보장은 없지만, 01 문서의 근거로 기본값은 p^).

E7. 신뢰 판정 규칙 재설계 예정

배경

E1 H2.3에서 폭 기준 0.15는 한 번도 만족되지 않았다. 구간 폭이 population 이질성을 그대로 반영하기 때문이다.

현재:  replicate r:  m_r ~ Unif{1..M},  idx_r ~ bootstrap,  A_r = AUROC(y[idx_r], p^(m_r)[idx_r])
       구간 = [pct_2.5(A), pct_97.5(A)],   폭에는 particle 분산 + bootstrap 분산이 모두 들어간다

대안 1 (폭 완화):   w_max = 0.3,  하한 조건 유지                                 -- 설정값으로 이미 가능
대안 2 (평균 예측): A_r = AUROC(y[idx_r], p^[idx_r])  (bootstrap만) + 별도로 particle 분산 보고
대안 3 (확률):      P(AUROC > 1/2 | data) = (1/R) sum_r 1[A_r > 1/2]  >= 0.95 를 신뢰 기준으로

가설

H7:  대안 3의 P(AUROC > 1/2)는 t에 대해 단조 증가하고, 긴 스트림 평가자에서 t = 20에 0.95를 넘는다

근거

폭 기준은 holdout 크기에 좌우되어 평가자 간 비교가 불공정하다. "우연보다 낫다는 사후 확률"은 크기에 덜 민감하고 Bayesian 해석이 직접적이다. 하한 0.5 조건은 사실상 대안 3의 0.975 기준과 같다.

설계

E4 실행에 w_max = 0.3을 쓰고, 리포트에 auroc_ci_width와 함께 P(AUROC > 1/2)를 추가한다(코드 추가 필요, replicate A_r을 이미 계산하므로 비용 없음). 판정은 E4 결과로 한다.

E8. prequential 곡선과 long-stream 사례 예정

prequential 누적 점수:  C_*(n) = sum_{i=1}^{n} log p( y_{*i} | D_{*,i-1}, D_pop )      (one-step-ahead, holdout 불필요)
비교 기준선:            C_pooled(n) = sum_i log p_pooled(y_{*i})
H8:  C_*(n) - C_pooled(n) 이 n에 대해 증가하는 기울기를 갖고, 긴 스트림 평가자에서 n ≈ 20 이후 양수로 유지된다

근거

01 문서 6절. 문맥/holdout 분할 없이 전체 스트림을 쓰므로 라벨이 적은 평가자에서도 정의되고, 누적 차이의 기울기가 "라벨 하나당 평균 이득"이다. 긴 스트림 다섯 명의 궤적은 논문 Fig. trajectory의 재료다.

설계

점수는 이미 report/prequential_cumulative.json에 저장된다(최대 120 스텝). pooled 기준선과 그림(평가자별 C_* - C_pooled vs n)을 리포트에 추가한다(코드 추가 필요). 추가 실행 불필요.
