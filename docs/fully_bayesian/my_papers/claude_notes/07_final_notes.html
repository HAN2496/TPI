0. 한 줄 요약

평가자별 로지스틱 계수에 정규 population 사전분포를 두고 NIW와 spike-and-slab까지 전부 Gibbs로 적분하는 계층 모형을 만들었다. 새 평가자는 population posterior predictive에서 시작해(cold start) Pólya–Gamma 갱신으로 개인화되고, posterior를 particle로 유지하므로 예측마다 epistemic/aleatoric 분해와 평가자 단위 신뢰 구간이 나온다. 실차 bump 2627 에피소드, 평가자 17명(적격 10명) LOEO에서 cold start는 pooled와 동등 이상(MLPD −0.692 vs −0.717), 라벨 20개에서 pooled보다 0.142 nat 좋고, indep는 t≤20 내내 cold start보다 나쁘다. epistemic은 단조 감소하며 t=20부터 오답을 가려내고, 센서는 수직 가속도 하나로 충분하다.

1. 문제 설정

평가자 \(u=1,\dots,U\), 에피소드 \(i\), 피처 \(\mathbf z_{ui}=\phi(\tau_{ui})\in\mathbb R^d\) (절편 포함), 라벨 \(y_{ui}\in\{0,1\}\) (1 = good).

\[ y_{ui}\sim\mathrm{Bernoulli}\big(\sigma(\boldsymbol\theta_u^\top\mathbf z_{ui})\big),\qquad \sigma(a)=\frac{1}{1+e^{-a}} \]

새 평가자 \(\star\)가 라벨 \(t\)개 \(\mathcal D_{\star,t}\)를 준 상태에서 미결 에피소드 \(j\)의 판단 확률을 예측한다.

\[ p(y_{\star j}=1\mid\mathbf z_{\star j},\mathcal D_{\star,t},\mathcal D_{1:U}) \]

\(t=0\)이 cold start, \(t\)가 늘어나는 과정이 sequential personalization이다. 요구 사항은 (i) population에서 새 평가자로 전이되는 표현, (ii) 작은 \(t\)에서의 갱신, (iii) 모든 \(t\)에서의 불확실성 정량화, 부수적으로 (iv) 어떤 피처와 센서가 필요한가.

2. 모형과 추론

2.1 계층 사전분포

\[ \boldsymbol\theta_u=\boldsymbol\gamma\odot\tilde{\boldsymbol\theta}_u,\qquad \tilde{\boldsymbol\theta}_u\mid\boldsymbol\mu,\boldsymbol\Sigma\sim\mathcal N(\boldsymbol\mu,\boldsymbol\Sigma),\qquad (\boldsymbol\mu,\boldsymbol\Sigma)\sim\mathrm{NIW}(\mathbf m_0,\kappa_0,\nu_0,\boldsymbol\Lambda_0) \] \[ \gamma_j=\gamma_g\ (j\in\mathcal C_g),\qquad \gamma_g\mid\pi\sim\mathrm{Bernoulli}(\pi),\qquad \pi\sim\mathrm{Beta}(1,1) \]

\(\mathbf m_0=\mathbf 0,\ \kappa_0=1,\ \nu_0=d+2,\ \boldsymbol\Lambda_0=\lambda_0\mathbf I,\ \lambda_0=1\) (피처가 표준화되어 있으므로). 마스크 \(\boldsymbol\gamma\)는 평가자 공통이다: \(\gamma_g=0\)은 "population의 누구도 그룹 \(g\)를 쓰지 않는다"는 뜻이고, 개인차는 \(\boldsymbol\Sigma\)로 표현된다. 그룹은 피처 하나(피처 수준) 또는 채널의 모든 피처(센서 수준)다. \(\boldsymbol\gamma\equiv\mathbf 1\)이면 HB-full, 포함 사전분포까지 켠 것이 proposed(reference model)다.

2.2 Pólya–Gamma Gibbs

\(\kappa_{ui}=y_{ui}-\tfrac12\), \(\omega_{ui}\sim\mathrm{PG}(1,\mathbf z_{ui}^\top\boldsymbol\theta_u)\), \(\boldsymbol\Omega_u=\mathrm{diag}(\boldsymbol\omega_u)\). 한 sweep은

\[ \mathbf A_u=\mathbf Z_u^\top\boldsymbol\Omega_u\mathbf Z_u+\boldsymbol\Sigma^{-1},\qquad \mathbf m_u=\mathbf A_u^{-1}\big(\mathbf Z_u^\top\boldsymbol\kappa_u+\boldsymbol\Sigma^{-1}\boldsymbol\mu\big),\qquad \boldsymbol\theta_u\mid\cdot\sim\mathcal N(\mathbf m_u,\mathbf A_u^{-1}) \] \[ \kappa_n=\kappa_0+U,\quad \nu_n=\nu_0+U,\quad \mathbf m_n=\frac{\kappa_0\mathbf m_0+U\bar{\boldsymbol\theta}}{\kappa_n},\quad \boldsymbol\Lambda_n=\boldsymbol\Lambda_0+\mathbf S+\frac{\kappa_0U}{\kappa_n}(\bar{\boldsymbol\theta}-\mathbf m_0)(\bar{\boldsymbol\theta}-\mathbf m_0)^\top,\quad (\boldsymbol\mu,\boldsymbol\Sigma)\mid\cdot\sim\mathrm{NIW}(\mathbf m_n,\kappa_n,\nu_n,\boldsymbol\Lambda_n) \]

마스크가 있으면 설계가 \(\mathbf X_u=\mathbf Z_u\,\mathrm{diag}(\boldsymbol\gamma)\)로 바뀌고, 그룹 \(g\)의 포함은 증강 우도로 닫힌 형태의 Bernoulli 갱신이 된다. \(c_{ui}\)를 그룹 \(g\)의 선형예측자 기여, \(h_{ui}\)를 그룹을 뺀 선형예측자라 하면

\[ \ell_g=\sum_{u}\sum_{i}\Big[\kappa_{ui}c_{ui}-\tfrac12\omega_{ui}\big(2h_{ui}c_{ui}+c_{ui}^2\big)\Big],\qquad p(\gamma_g=1\mid\cdot)=\sigma\!\Big(\log\tfrac{\pi}{1-\pi}+\ell_g\Big),\qquad \pi\mid\boldsymbol\gamma\sim\mathrm{Beta}\big(1+\textstyle\sum_g\gamma_g,\ 1+G-\sum_g\gamma_g\big) \]

burn-in \(B=500\), 보존 \(M=1500\) sweep. 보존된 \(\{(\boldsymbol\mu^{(m)},\boldsymbol\Sigma^{(m)},\boldsymbol\gamma^{(m)},\boldsymbol\theta^{(m)}_{1:U})\}_{m=1}^M\)이 population posterior이며 어떤 단계에서도 점으로 축약하지 않는다. PIP는 \(M^{-1}\sum_m\gamma_g^{(m)}\).

2.3 Cold start와 개인화

\[ p(\boldsymbol\theta_\star\mid\mathcal D_{1:U})=\int\mathcal N(\boldsymbol\theta_\star;\boldsymbol\mu,\boldsymbol\Sigma)\,p(\boldsymbol\mu,\boldsymbol\Sigma\mid\mathcal D_{1:U})\,d\boldsymbol\mu\,d\boldsymbol\Sigma \quad\Longrightarrow\quad \tilde{\boldsymbol\theta}^{(m)}_\star\sim\mathcal N(\boldsymbol\mu^{(m)},\boldsymbol\Sigma^{(m)}),\ \ \boldsymbol\theta^{(m)}_\star=\boldsymbol\gamma^{(m)}\odot\tilde{\boldsymbol\theta}^{(m)}_\star \]

particle \(m\)마다 \((\boldsymbol\mu^{(m)},\boldsymbol\Sigma^{(m)},\boldsymbol\gamma^{(m)})\)을 고정하고 \(\mathcal D_{\star,t}\)로 PG sweep \(n_{\mathrm{it}}=8\)회를 돌린다 (이전 예산에서 warm start). 비용은 particle당 \(d\times d\) Cholesky 하나이고 \(m\)에 대해 병렬이다. 예측은 particle 평균이다.

\[ p^{(m)}_{\star j,t}=\sigma\big(\mathbf z_{\star j}^\top\boldsymbol\theta^{(m)}_{\star,t}\big),\qquad \hat p_{\star j,t}=\frac1M\sum_{m=1}^M p^{(m)}_{\star j,t} \]

3. 불확실성

전체 분산 법칙으로 Bernoulli 분산을 정확히 둘로 나눈다.

\[ \underbrace{\hat p_j(1-\hat p_j)}_{\text{total}} =\underbrace{\mathbb E_m\big[p^{(m)}_j(1-p^{(m)}_j)\big]}_{U^{\mathrm{ale}}_j} +\underbrace{\mathrm{Var}_m\big(p^{(m)}_j\big)}_{U^{\mathrm{epi}}_j} \]

\(U^{\mathrm{ale}}\)는 평가자 자신의 판단이 동전 던지기에 가까운 정도(피드백으로 안 줄어듦), \(U^{\mathrm{epi}}\)는 particle 간 불일치(개인화되면 줄어듦). holdout 평균 \(\bar U^{\mathrm{epi}}(t),\bar U^{\mathrm{ale}}(t)\)를 곡선으로 보고한다.

평가자 단위 신뢰 구간: replicate \(r=1..K\) (\(K=600\))마다 particle \(m_r\)과 holdout bootstrap \(\mathrm{idx}_r\)을 뽑아 \(A_r=\mathrm{AUROC}(y[\mathrm{idx}_r],p^{(m_r)}[\mathrm{idx}_r])\), 2.5/97.5 백분위가 \([\mathrm{AUROC}_{\mathrm{lo}},\mathrm{AUROC}_{\mathrm{hi}}]\).

\[ \text{reliable}(t)\iff \mathrm{AUROC}_{\mathrm{lo}}(t)>\tfrac12\ \wedge\ \mathrm{AUROC}_{\mathrm{hi}}(t)-\mathrm{AUROC}_{\mathrm{lo}}(t)Jensen 수축 진단용 plug-in 예측도 같이 계산한다: \(\tilde p_j=\sigma(\mathbf z_j^\top\bar{\boldsymbol\theta})\), \(|\hat p_j-\tfrac12|\le|\tilde p_j-\tfrac12|\).

4. 피처 bank와 선택

채널 5개(\(a_x,a_y,a_z\): IMU 가속도; \(\dot z,\dot\theta\): 6D bounce/pitch rate), 창 −2~+2 s, 10 Hz 저역통과 후 50 Hz, \(T=200\). 통계 다섯 계열: 진폭(abs peak, p2p, 95% of \(|x|\)), 에너지(RMS, sd, impulse), 형태(crest, 4제곱 dose, 1초 running RMS max), ISO 가중 RMS(\(W_k,W_d,W_e\)), 밴드(0.5–5 Hz RMS, 1–2 / 4–8 Hz 상대 에너지). rate 채널은 미분값에도 적용.

중복 제거: population 에피소드에서 같은 채널 내 \(|\rho|\ge0.95\)인 쌍 중 우선순위가 낮은 열을 greedy로 제거. 결과 \(a_z\) 10, \(a_x\) 8, \(a_y\) 8, \(\dot z\) 7, \(\dot\theta\) 7 = 40, 절편 포함 \(d=41\). 표준화 상수와 함께 held-out 평가자를 보기 전에 고정.

선택 절차 두 개가 모형에 붙는다.

  1. Spike-and-slab PIP (2.1절). 피처 수준과 센서 수준 두 번 실행.
  2. Projection-predictive forward search. draw \(m\), 평가자 \(u\), 열 집합 \(S\)에 대해 \[ \hat{\mathbf b}^{(m,u)}_S=\arg\min_{\mathbf b}\sum_i\mathrm{KL}\Big[\mathrm{Bern}(p^{(m)}_{ui})\,\Big\|\,\mathrm{Bern}\big(\sigma(\mathbf z_{ui,S}^\top\mathbf b)\big)\Big],\qquad L(S)=\frac{1}{M'\sum_uN_u}\sum_{m,u,i}\mathrm{KL}[\cdot\|\cdot] \] \(M'=12\). 경로는 \(L\)이 정하고 크기는 폴드 내 held-out MLPD 재적합(축소 체인 200+400, 예산 \(\{0,10,20\}\) 평균) + one-SE 규칙이 정한다. 센서는 \(2^5-1=31\) 부분집합 전수 재적합.

역할 분류. inactive: \(\mathrm{PIP}_j<\tfrac12\). 포함된 피처는 부호 일치 확률로 나눈다.

\[ q_j=\mathbb E_m\!\left[\Phi\!\left(\frac{|\mu^{(m)}_j|}{\sqrt{\Sigma^{(m)}_{jj}}}\right)\right],\qquad \text{common: } q_j\ge0.9,\quad \text{specific: otherwise};\qquad S_j=\mathbb E_m\big[(\mu^{(m)}_j)^2+\Sigma^{(m)}_{jj}\big] \]
